# 独自タイピングシステム 問題・問題セット仕様

| 項目 | 内容 |
| --- | --- |
| 文書状態 | v1コア仕様決定済み |
| 最終更新 | 2026-08-02 |

## 1. 問題セット

- 第1〜第3試合で別々の問題セットを使用する。
- 3つの問題セットは主催者が同程度の難易度になるよう調整する。
- 同じ試合の6名へ、同じ問題セットを同じ順番で出題する。
- 各問題セットに不変の`problem_set_id`と1以上の`version`を持たせる。
- 問題を変更した場合は`version`を増加させる。
- 試合開始時に問題セットID、バージョン、問題順を固定し、競技終了まで変更しない。
- 再試合では、運営者が再試合用として確定した問題セットとバージョンを6名共通で使用する。

## 2. 問題データ

各問題は最低限、次を持つ。

| フィールド | 説明 |
| --- | --- |
| `problem_id` | 問題セット内で一意な不変ID |
| `display_text` | 選手画面へ表示する文章 |
| `reading` | 入力判定に使用する読み |
| `order` | 問題セット内の出題順 |

- `display_text`には漢字を使用してよいが、入力判定には`reading`を使用する。
- `reading`はひらがな、カタカナ、長音符「ー」、読点「、」、句点「。」だけで構成する。
- `display_text`と`reading`へスペースを含めない。
- Shiftを必要とする英大文字、英数字、記号は入力対象へ含めない。

## 3. 問題進行

- 競技時間中は問題を`order`順に出題し続ける。
- 問題の最後の入力を正しく完了した時点で完了とする。
- Enterなどの追加操作を要求せず、自動的に次の問題へ進む。
- 競技終了時点で入力途中の問題は完了問題数へ含めないが、終了前の正・誤タイプ数は正式集計へ含める。
- 最終問題を完了した後の動作は、問題セットの先頭へ戻って継続する方式とする。

## 4. 公平性と固定

- 3つの問題セットについて、文字数、読みの長さ、使用文字、ローマ字入力の複雑さが大きく偏らないよう主催者が確認する。
- 問題セットの選択、順序、バージョンを試合開始前に運営画面で確認できること。
- 試合開始後は問題の追加、削除、並べ替え、修正、差し替えを禁止する。
- 競技結果へ使用した問題セットIDとバージョンを保存する。

## 5. 実装者の裁量

- 問題管理画面のレイアウトと編集操作。
- 問題のカテゴリ、説明、タグなどの追加メタデータ。
- 問題切り替え時の表示演出。
- コア条件を満たす問題セット作成支援や難易度分析。
